This program sends one joke about Monday mornings, and that line is the whole entry and nothing else. It writes the joke to `entry.txt` as UTF-8, then reads it back to prove the bytes match.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
